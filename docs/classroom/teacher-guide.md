# 教師操作手冊

## 課前

1. 用電腦或平板打開 `…/classroom/teacher`，以學校給的教師帳號登入（mock 模式不用登入）。
2. 準備導覽：
   - 預設是三站示範導覽，可直接使用。
   - 「＋ 上傳 2:1 全景照片」加入自己的場景（JPG/PNG/WebP，25 MB 內）。照片會重新壓縮並**移除 GPS 等 EXIF 資訊**。
     請只使用自己拍攝或有授權的照片。
   - 每站可以改名稱、寫介紹（介紹會自動成為該站解說卡的預設內容），用 ▲▼ 調整順序。
3. 選擇教室開放時間（50 分鐘 / 2 小時 / 4 小時），按「建立教室」。

## 上課

| 操作 | 學生會看到 |
| --- | --- |
| 投影「教室代碼」與 QR Code（點 QR Code 可放大） | 掃碼或輸入代碼加入 |
| **下一站 ▶ / ◀ 上一站 / 指定場景** | 全班切到同一個場景（跟隨模式時） |
| 在預覽畫面把白色圓圈對準目標，按 **看這裡** | 紅色圓圈標記 + 邊緣箭頭 +「向右轉約 60°」提示；學生仍可自由轉頭 |
| **解除引導** | 提示消失 |
| **解說卡 ▶ 播放 / ❚❚ 暫停** | 畫面下方出現 / 收起文字卡（只顯示純文字） |
| **A 跟隨導覽 / B 自由探索** | B：學生可自己挑場景；切回 A 時全班自動回到老師的場景 |
| **結束課堂** | 學生畫面顯示「導覽結束」，代碼立刻失效 |

- 左側「線上學生」列出暱稱與「✓ 已同步 / 同步中」，可以確認大家是否都收到最新指令。
- 每次操作下方會顯示「已送出（#序號）」；失敗會顯示原因，可再按一次。
- 老師重新整理頁面會自動接回原本的教室。

## 注意

- 老師**不能**遠端開啟學生的 VR 模式或陀螺儀，這些都要學生自己按。
- 學生只用暱稱，提醒他們不要輸入真實姓名。
- 課堂結束 24 小時後，匿名學生的暱稱與操作紀錄會自動刪除（需啟用排程，見 README）。
