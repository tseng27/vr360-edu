# 學生操作手冊

1. 用手機相機掃老師螢幕上的 QR Code，或打開 `…/classroom/join` 輸入 **6 碼代碼**。
2. 取一個暱稱（**不要用真實姓名**），按「進入教室」。不需要帳號、不需要安裝 App。
3. 看四周：
   - 電腦：用滑鼠拖曳。
   - 手機 / 平板：用手指拖曳；或按下方 🧭 按鈕開啟陀螺儀，轉動手機看四周（iPhone 會跳出權限詢問，請按「允許」）。
4. 老師換場景時，你的畫面會自動跟著換。
5. 看到紅色提示「老師請你看這裡」：照著箭頭轉頭，或按「前往老師指定方向」自動轉過去。
6. 「自由探索」時，下方會出現場景縮圖，可以自己選要去哪裡。
7. 有 VR 頭盔、而且瀏覽器支援時，右上角會出現「進入 VR」；沒有出現就代表這台裝置用一般 360° 模式。

## 想要像 App 一樣開啟？

- iPhone / iPad（Safari）：分享 → 加入主畫面。
- Android（Chrome）：⋮ 選單 → 加到主畫面 / 安裝應用程式。

## 遇到問題

| 狀況 | 怎麼辦 |
| --- | --- |
| 「找不到這個教室代碼」 | 再看一次代碼；沒有 0、O、1、I、L 這幾個字 |
| 「連線中斷，正在重新連線…」 | 檢查 Wi-Fi；按「立即重試」。重連後會自動跟上老師目前的場景 |
| 全景圖載入失敗 | 按「重新載入」；仍失敗請告訴老師 |
| 不小心關掉頁面 | 重新掃 QR Code、輸入同一個暱稱即可 |
